    Floor 150 · Under the hood

    A few commands, zero magic

    The game is a pure function of (seed, inputs). That makes it testable, replayable, and easy for bots to play.

    
          
    

          
    
            
    
              
    Write your own agent
    
              
    An agent sees an Observation each tick and returns an input bitmask. No DOM, so it runs in Node at thousands of ticks per second.
    
            
    
            
    import type { Agent } from './src/agents/api';
import { INPUT_JUMP, INPUT_RIGHT } from './src/engine/constants';

export const bunnyHop: Agent = {
  name: 'Bunny hop',
  act: (obs) => obs.player.grounded
    ? INPUT_RIGHT | INPUT_JUMP
    : INPUT_RIGHT,
};

      🐧
      Pick your climber
      Continue as yourself, choose your name from the list, or make a new climber. Names are unique, and your scores follow you to any machine.
      
          
      🔐
      Optional PIN
      Lock your climber with a 4-digit PIN, so nobody else can play as you from another desk.
      
          
      🤝
      No admin needed
      Anyone can remove a climber, and anyone can restore them for 7 days. Everybody sees who removed whom, with an Undo.
      
          
      🏆
      Tournaments
      From a 5-minute sprint to a month-long cup. One tower for everyone, an optional attempt limit, and the winner announced live.
      
          
      📺
      Big-screen board
      Put /tv on the office TV: standings with a countdown, who's climbing right now, and a feed of new records.
      
          
      🛡️
      Scores you can trust
      Players send replays, not scores. The server re-runs every run before it counts, so nobody can post a fake one.
